SAINTS SIDELINE – putting it online

1. Go to https://app.netlify.com/drop and sign up for a free account (so the site stays up).
2. Unzip the download, then drag the whole "saints-sideline" folder onto the page. Netlify gives you a web address.
3. Optional: in Site settings > Change site name, pick something like saints-sideline,
   so the address becomes saints-sideline.netlify.app.

On your wife's phone
- iPhone: open the address in Safari > Share button > Add to Home Screen > Add.
- Android: open the address in Chrome > ⋮ menu > Add to Home screen (or Install app).
Open it once with wifi or data so it saves itself for offline use. After that it works in the gym with no signal.

Good to know
- The squad and game history are saved on each phone separately.
- To update the app later, drag the new folder onto the same site in Netlify (Deploys > drag and drop).
